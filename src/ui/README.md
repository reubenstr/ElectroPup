# ElectroPup UI

Expo (SDK 57) + expo-router app. Source lives in [src/](./src), routes in [src/app/](./src/app).

## Get started

```bash
yarn install
yarn ios      # or: yarn android
```

Styling is handled by [Unistyles](https://www.unistyl.es/) — it requires native code, so
this app runs in a development build, not Expo Go.
